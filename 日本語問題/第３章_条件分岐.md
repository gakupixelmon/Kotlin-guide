# 条件分岐

Kotlinの条件分岐は、C言語やPythonと似ていますが、より強力で安全な機能（**式として扱える**点など）が備わっています。

このドキュメントでは、基本の `if` から、Kotlin最強の構文の一つである `when` までを丁寧に解説します。

---

## 1. if 式 (if expression)

基本の書き方はC言語やJavaと同じですが、Kotlinの `if` は「値を返す」ことができるのが最大の特徴です。

### 基本的な書き方
C/C++ と全く同じです。

```kotlin
var a = 10
var b = 20

if (a > b) {
    println("aの方が大きいです")
} else {
    println("bの方が大きいです")
}
```
問題1
aとbの和がaとbの積よりも大きい場合に「和のほうが大きい」と表示するコードを作成しましょう。a,bの値は各自で設定しましょう。
```
fun main() {
    val a;
    val b;
    
    // ここから変える
}
```
答え
```

fun main() {
    val a = 5
    val b = 10
    
    // ifの結果を変数に入れる
    val result = if (a + b > a * b) "和の方が大きい" else "積の方が大きい"
    
    println(result)
}
```
```
【重要】式としての if（値を返す）
ここがKotlinの大きな特徴です。
C言語にある「三項演算子 (a > b) ? a : b」(a>bならばa、そうでないならばbとなる演算子)は、Kotlinには存在しません。代わりに、ifを使って変数に値を直接代入します。

```
val a = 10
val b = 20

// if の結果を変数 max に直接入れる
// 最後に書いた値が「戻り値」になります
val max = if (a > b) {
    println("aを選択")
    a // これが max に入る
} else {
    println("bを選択")
    b // これが max に入る
}

println("最大値は $max です")
```

## 2.when 式 (when expression)
C/C++ の switch 文に相当しますが、はるかに高機能です。
break 文を書く必要はありません。 条件に一致した時点で自動的に抜けます。

基本的な書き方（値の一致）
```
val x = 1

when (x) {
    1 -> println("xは 1 です")
    2 -> println("xは 2 です")
    else -> { // switch の default に相当
        println("xは 1 でも 2 でもありません")
    }
}
```
複数の条件をまとめる
カンマ , で区切ることで、複数の条件を一行で書けます。
```
val x = 1

when (x) {
    0, 1 -> println("0 か 1 です")
    else -> println("それ以外です")
}
```

【強力】範囲や型での分岐
定数だけでなく、範囲 (in) や 型チェック (is) も使えます。これが switch との決定的な違いです。
```
val score = 85

when (score) {
    in 0..59 -> println("赤点です")       // 0以上59以下
    in 60..79 -> println("合格です")      // 60以上79以下
    in 80..100 -> println("優秀です！")   // 80以上100以下
    else -> println("無効な点数です")
}
```

【重要】式としての when（値を返す）
if と同様に、when も結果を変数に代入できます。
```
val color = "Red"

val message = when (color) {
    "Red" -> "止まれ"
    "Yellow" -> "注意"
    "Green" -> "進め"
    else -> "故障中" // 式として使う場合は else が必須
}

println(message) // "止まれ" と表示される
```

## 3. スマートキャスト (Smart Casts)
条件分岐の中で is (型チェック) を使うと、Kotlinは自動的にその変数をキャスト（型変換）してくれます。
```
val x: Any = "Hello" // Anyは「すべての型」の親（Cのvoid*に近いが安全）

if (x is String) {
    // このブロック内では、x は自動的に String として扱われる
    println(x.length) // .length が使える！
}
```

### 問題
以下のコードを実行したとき、コンソールに何が表示されるか予想してください。


問題2
```
fun main() {
    val x = 2
    
    when (x) {
        1 -> println("One")
        2 -> println("Two")
        3 -> println("Three")
        else -> println("Other")
    }
}
```

問題3
```
fun main() {
    val y = 15
    
    when (y) {
        in 1..10 -> println("Low")
        in 11..20 -> println("Middle")
        else -> println("High")
    }
}
```

問題4
```
fun main() {
    val signal = "Blue"
    
    // 変数 action に when の結果を入れる
    val action = when (signal) {
        "Red" -> "Stop"
        "Yellow" -> "Caution"
        else -> "Go"
    }
    
    println(action)
}
```

問題5
```
fun main() {
    val obj: Any = 100 // Int型のデータを入れる
    
    when (obj) {
        is String -> println("It is a String")
        is Int -> println("It is an Integer")
        else -> println("Unknown")
    }
}
```

問題2 Two  
x は 2 なので、2 -> ... の行が実行されます。break は不要です。

問題3 Middle
15 は 11..20 の範囲内に含まれるため、in 11..20 の行がマッチします。

問題4 Go
signal は "Blue" ですが、条件に "Blue" がないため else に進み、"Go" が返されます。

問題5 It is an Integer
obj には 100 (Int) が入っています。is Int で型チェックが成功し、その行が実行されます。
