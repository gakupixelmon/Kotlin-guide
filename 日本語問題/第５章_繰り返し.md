# Kotlin 重要な構文：ループ
プログラムを効率的に書くための「繰り返し」について解説します。
C/C++などの`for` 文とは考え方が少し違うので注意してください。  
---

## 1. ループ処理 (Loops)

Kotlinの `for` は、**「範囲（Range）」**や**「コレクション」**をなぞる形（イテレータ）で書きます。
C言語のような `for(int i=0; i<10; i++)` という書き方はしません。

### A. 指定回数の繰り返し (`..` と `until`)

最もよく使うパターンです。

```kotlin
// 1から5まで (1, 2, 3, 4, 5)
// ".." は「以下 (Inclusive)」です
for (i in 1..5) {
    println(i)
}

// 0から4まで (0, 1, 2, 3, 4)
// "until" は「未満 (Exclusive)」です。配列の添字でよく使います。
for (i in 0 until 5) {
    println(i)
}
```
### B. 逆順とステップ (downTo, step)
```
// 10から0まで、2刻みで減らす (10, 8, 6, 4, 2, 0)
for (i in 10 downTo 0 step 2) {
    println("Count: $i")
}
```

### C. リストの中身を回す
C++の範囲for文 (for(auto x : list)) や Python (for x in list:) と同じです。  
```
val robots = listOf("Drone", "Arm", "Rover")

for (robot in robots) {
    println("Robot name: $robot")
}

// インデックス（何番目か）も欲しい場合
for ((index, value) in robots.withIndex()) {
    println("$index 番目のロボット: $value")
}
```

### D. Whileループ
これはC/C++と全く同じです。
```
var x = 5
while (x > 0) {
    println(x)
    x--
}
```

# 問題
以下のコードを実行したとき、コンソールに何が表示されるか予想してください。
### 第1問：ループの範囲
```
fun main() {
    // 0 until 3 なので、3は含まれる？含まれない？
    for (i in 0 until 3) {
        print(i)
    }
}
```

### 第2問: ステップ実行
```
fun main() {
    var sum = 0
    // 1, 3, 5 を足す
    for (i in 1..5 step 2) {
        sum += i
    }
    println(sum)
}
```

## 答え
第1問: 012  
until は「未満」なので、3は含まれません。配列のサイズ分だけ回すときなどに使います。  

第2問: 9  
1..5 step 2 は 1, 3, 5 となります。
1 + 3 + 5 = 9 です。
