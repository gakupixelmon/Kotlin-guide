### クラス
複数のデータをひとまとめにして「型」を作る機能です。Kotlinのクラスは非常に短く記述できます。
※ Kotlinでは、インスタンス化（オブジェクトの作成）の際に new キーワードを使用しません。  
### A. 基本的なクラスの定義
クラス名の直後に「プライマリコンストラクタ（主初期化子）」を書くことで、変数の定義と初期化を同時に行えます。
```
// "name" は変更不可 (val)、"age" は変更可能 (var) なプロパティとして定義
class Person(val name: String, var age: Int)

fun main() {
    // new は不要です
    val p1 = Person("Tanaka", 20)
    
    println(p1.name) // Tanaka
    
    p1.age = 21      // var なので変更可能
    println(p1.age)  // 21
}
```

# データクラス (Data Classes)
「ただデータを保持するだけ」のクラスを作る場合、先頭に data をつけるだけで、非常に強力な機能が自動的に追加されます。
データの比較や、ログ出力が劇的に楽になります。
### データクラスの恩恵
自動的に equals() (同値比較)、hashCode()、toString() (文字列表現)、copy() などのメソッドが生成されます。
```
// data をつけるだけ
data class Robot(val id: Int, val model: String)

fun main() {
    val r1 = Robot(1, "Type-A")
    val r2 = Robot(1, "Type-A")
    
    // 1. 綺麗な文字列として出力される (toStringの自動生成)
    println(r1) // 出力: Robot(id=1, model=Type-A)
    
    // 2. 中身が同じなら true になる (equalsの自動生成)
    println(r1 == r2) // true
    
    // 3. 一部だけ変更して複製する (copyメソッドの自動生成)
    val r3 = r1.copy(id = 2)
    println(r3) // 出力: Robot(id=2, model=Type-A)
}
```

# 問題
以下のコードを実行したとき、どのような結果になるか、あるいはエラーになるか答えてください。
### 第１問 クラスのインスタンス化
```
class Car(val color: String)

fun main() {
    // Kotlinで以下の書き方は正しいですか？
    // val myCar = new Car("Red")
    val myCar = Car("Red")
    println(myCar.color)
}
```

### 第2問：データクラスの同値比較
```
data class Point(val x: Int, val y: Int)

fun main() {
    val p1 = Point(10, 20)
    val p2 = Point(10, 20)
    
    // データクラスの場合、これは true になりますか？
    println(p1 == p2)
}
```

### 第3問: データクラスのコピー
```
data class User(val name: String, val isActive: Boolean)

fun main() {
    val user1 = User("Alice", true)
    // 名前はそのままで、isActive だけ false にして複製
    val user2 = user1.copy(isActive = false)
    
    println(user2.name)
    println(user2.isActive)
}
```

## 解答
第1問: 下の行 (newがない方) が正しく、Red と出力される 
Kotlinには new キーワードが存在しません。関数を呼び出すのと同じように Car("Red") と書くことでインスタンス化（オブジェクトの作成）が行われます。  

第2問: true
data class は、内部のプロパティ（x と y）の値がすべて等しければ == 演算子で true を返すように、内部で自動的に比較処理が作られます（通常の class の場合は false になります）。  

第3問: Alice / false
copy() メソッドを使うと、指定したプロパティ（ここでは isActive）だけを変更し、それ以外のプロパティ（name の "Alice"）は元のインスタンスから引き継いだ新しいインスタンスを作成できます。
