# Kotlin 標準ライブラリ基礎 (Collections & Utils)

Kotlinの標準ライブラリは強力で、追加のインストールなしですぐに使えます。
特に重要な **コレクション（リストや辞書）**、**文字列操作**、**数学関数**、**入力**について解説します。

---

## 1. List (リスト)

C++の `std::vector`、Pythonの `list` に相当します。
Kotlinでは、「読み取り専用」と「書き込み可能」を明確に使い分けます。

### A. 読み取り専用リスト (`listOf`)
作成後は要素の追加・削除・変更が一切できません。**基本はこちらを使います。**

```kotlin
// 変更不可 (Immutable List)
val numbers = listOf(1, 2, 3, 4, 5)

println(numbers[0])   // 1 (アクセスはOK)
println(numbers.size) // 5 (サイズ取得)

// numbers.add(6)     // エラー！追加できない
// numbers[0] = 10    // エラー！書き換えできない
```

### B.変更可能リスト ('mutableListOf')
後から変更が必要な場合のみ、こちらを使います。
```
// 変更可能 (Mutable List)
val fruits = mutableListOf("Apple", "Banana")

fruits.add("Orange")  // 追加
fruits[0] = "Peach"   // 上書き
fruits.removeAt(1)    // 削除 (Bananaを消す)

println(fruits) // [Peach, Orange]
```
注意: 変数自体の定義は val (参照の固定) であっても、中身が Mutable なら操作可能です。

## 2. Map (マップ / 連想配列)
KeyとValueのペアでデータを管理します。Pythonの dict、C++の std::map に相当します。
to というキーワードを使ってペアを作ります。
```
// 読み取り専用マップ
// "キー" to "値" という書き方をする
val scores = mapOf(
    "Math" to 90,
    "English" to 80,
    "Physics" to 95
)

println(scores["Math"]) // 90
// scores["Math"] = 100 // エラー！変更不可

// 変更可能マップ
val user = mutableMapOf(
    "id" to 1,
    "name" to "Tanaka"
)

user["name"] = "Suzuki" // 上書きOK
user["age"] = 20        // 新規キーの追加OK
```

## 3. 文字列操作 (String)
Stringクラスには便利なメソッドが多数用意されています。
```
val text = "Kotlin is Fun"

println(text.length)        // 文字数: 13
println(text.uppercase())   // 大文字変換: "KOTLIN IS FUN"
println(text.lowercase())   // 小文字変換: "kotlin is fun"

// 文字列が含まれているか判定
if (text.contains("Fun")) {
    println("楽しそうです")
}

// 文字の置き換え
val newText = text.replace("Fun", "Great")
println(newText) // "Kotlin is Great"
```

## 4. 数学関数 (Math)
基本的な計算関数は kotlin.math パッケージにあります。
これらは手動でインポートするか、IDEの自動補完に任せます。
```
import kotlin.math.* // 数学関数をすべて読み込む

fun main() {
    val x = 2.0
    val y = 3.0

    println(max(x, y))  // 最大値: 3.0
    println(min(x, y))  // 最小値: 2.0
    println(sqrt(16.0)) // 平方根: 4.0
    println(x.pow(3))   // 累乗 (2の3乗): 8.0
    
    println(PI)         // 円周率: 3.14159...
}
```

## 5. 標準入力 (Standard Input)
ユーザーからの入力を受け取るには readln() を使います。
受け取ったデータは必ず String型 になるため、数値として使いたい場合は変換が必要です。
```
fun main() {
    print("名前を入力してください: ")
    val name = readln() // 文字列として受け取る
    
    print("年齢を入力してください: ")
    // 文字列を受け取ってから Int に変換する (.toInt())
    val ageString = readln()
    val age = ageString.toInt() 

    println("${name}さんは来年 ${age + 1} 歳ですね。")
}
```
