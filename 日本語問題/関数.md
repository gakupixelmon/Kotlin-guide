# 関数定義 (Functions)
関数は fun キーワードで定義します。
Kotlinの関数は「式」として書くこともでき、非常に短く記述できます。
### A. 基本的な関数
「引数の型」と「戻り値の型」を必ず指定します。以下のように、mainも関数です。
```
// fun 関数名(引数名: 型): 戻り値の型 { ... }
fun add(a: Int, b: Int): Int {
    return a + b
}

fun main() {
    val result = add(10, 20)
    println(result)
}
```

### B. 単一式関数 (Single-expression function)
ここが重要です。
関数の中身が「計算して返すだけ」の場合、{ } と return を省略して = で繋ぐことができます。Kotlinではこの書き方が非常に好まれます。  
```
// 上の add 関数と同じ意味です
fun addSimple(a: Int, b: Int): Int = a + b

// 型推論が効くので、戻り値の型すら省略可能です
fun multiply(a: Int, b: Int) = a * b
```
### C. 名前付き引数とデフォルト引数
Pythonのような便利な呼び出し方ができます。
```
// メッセージにデフォルト値を設定
fun greet(name: String, message: String = "Hello") {
    println("$message, $name!")
}

fun main() {
    greet("Tanaka")                  // Hello, Tanaka!
    greet("Suzuki", "Good morning")  // Good morning, Suzuki!
    
    // 引数の順番を変えて指定することも可能
    greet(message = "Hi", name = "Sato") 
}
```

# 問題  
以下のコードを実行したとき、コンソールに何が表示されるか予想してください。
### 第一問 単一式関数
```
// この関数は正しく動きますか？また結果は何ですか？
fun square(x: Int) = x * x

fun main() {
    println(square(4))
}
```
### 第二問 デフォルト引数
```
fun power(base: Int, exponent: Int = 2): Int {
    // Math.pow は Double を使うので簡易的にループで計算
    var result = 1
    for (i in 1..exponent) {
        result *= base
    }
    return result
}

fun main() {
    println(power(3)) // 第2引数を省略
}
```

## 答え
第一問: 16
正しく動きます。fun square(x: Int): Int = x * x の : Int が型推論により省略されています。
4 * 4 = 16 です。

第二問: 9
exponent（指数）のデフォルト値が 2 に設定されています。
呼び出し時に省略したため、3 の 2 乗が計算され、結果は 9 になります。
