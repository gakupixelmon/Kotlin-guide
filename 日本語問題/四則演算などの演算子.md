# 演算子

この章では覚えることが多くて大変に思えるはずです。全てを一度に覚える必要はなく、存在をなんとなく知っているところを最初は目指しましょう。そうすれば必要になった時に検索することができます。
## 四則演算
割り算、余り以外特に注意することはありません。  
| 演算子 | 意味 | C/C++ との違い・注意点 |
| :---: | :--- | :--- |
| `+` | 加算 (足し算) | 文字列結合にも使用可能 |
| `-` | 減算 (引き算) | |
| `*` | 乗算 (掛け算) | |
| `/` | 除算 (割り算) | **整数同士は切り捨て** (例: `5 / 2` → `2`) |
| `%` | 剰余 (あまり) | |
整数同士の割り算の切り捨ては単純に小数点以下をなくせば良い、つまり
商を超えない最大の整数でなく、絶対値が商を超えない最大の整数に商と同じ符号をつけたものです。
剰余(あまり)について補足しておくと、割られる数が負なら結果も負になります。(例 -7 % 3 は -1)  
剰余を正で表す関数がKotlinにはあります。(例 (-7).mod(3) は 2。　これは 3 + (-7 % 3)とも表せる。)  
また小数で剰余を計算した場合、結果は ```(割られる数)-(割る数)×(商の整数部分)``` になります。商の整数部分は単純に小数点以下をなくせば良い、つまり
商を超えない最大の整数でなく、絶対値が商を超えない最大の整数に商と同じ符号をつけたものです。
(例 -3.14 % -1.41 は -3.14 - (-1.41)×2 となり、 -0.32)

## インクリメント、デクリメント
x = x + 1 のように、xに次の整数などを代入する方法としてインクリメント、デクリメントがあります。
| 演算子 | 意味 | C/C++ との違い・注意点 |
| `++` | インクリメント | `val` 変数には使用不可 |
| `--` | デクリメント | `val` 変数には使用不可 |
例
```
var count = 0
count++  // count = count + 1 と同じ
println(count) // 1

count--  // count = count - 1 と同じ
println(count) // 0
```

## 比較演算子
===と!==があるのがKotlinの特徴です。
| 演算子 | 意味 | C/C++ との違い・注意点 |
| :---: | :--- | :--- |
| `==` | **値が等しい** (構造的等価) | Javaの `.equals()` 相当。**通常はこちらを使用** |
| `!=` | 値が等しくない | |
| `===` | **参照が等しい** (参照的等価) | メモリ上の場所が同じか比較 (C++のポインタ比較に近い) |
| `!==` | 参照が等しくない | |
| `<` `>` | 大なり・小なり | |
| `<=` `>=` | 以上・以下 | |

## ビット演算 (Bitwise)
※ Kotlinでは記号ではなく「中置関数 (Infix Function)」を使います。

| 関数名 | 意味 | C/C++ 表記 |
| :---: | :--- | :--- |
| `shl` | 左シフト (符号付き) | `<<` |
| `shr` | 右シフト (符号付き) | `>>` |
| `ushr` | 右シフト (符号なし/0埋め) | `>>>` (Java), C++の `unsigned` シフト |
| `and` | ビットごとのAND | `&` |
| `or` | ビットごとのOR | `\|` |
| `xor` | 排他的論理和 | `^` |
| `inv()` | ビット反転 (NOT) | `~` |

## Null安全・特殊演算 (Null Safety & Others)
| 演算子 | 名称・意味 | 使用例 |
| :---: | :--- | :--- |
| `?.` | 安全呼び出し (Safe Call) | `s?.length` (nullならnullを返す・落ちない) |
| `?:` | エルビス演算子 (Elvis Operator) | `val l = s?.length ?: 0` (nullなら0を代入) |
| `!!` | 非null表明 (Not-null Assertion) | `s!!.length` (nullなら例外発生して落ちる。**基本非推奨**) |
| `..` | 範囲 (Range) | `if (i in 1..10)` (1以上10以下) |
| `in` | 含まれるか判定 | `if (x in list)` |
| `is` | 型チェック | `if (obj is String)` (instanceof 相当) |

### 問題1
println()は文字を表示した後改行する関数です。(つまりprint()とprint("\n"))
問題1~5ではprintln()で表示されるものを答えましょう。実際に実行してみるよりは頭の中で何が出るか理解している可の問題です。
```
fun main() {
    val x = 10
    val y = 4
    
    // 整数同士の割り算と、文字列への結合
    println("Answer: " + (x / y))
    
    // 剰余（あまり）
    println(x % y)
}
```

### 問題3

fun main() {
    val isSunny = true

    // 晴れ かつ 寒い ？

### 問題4
```
fun main() {
    val num = 2 // 2進数: 0010
    
    // 左に1ビットシフト (0010 -> 0100)
    println(num shl 1)
    
    // ビットごとのOR (0010 OR 0001 -> ????)
    println(num or 1)
}
```

### 問題5
```
fun main() {
    val name: String? = null
    
    // nullに対してアクセスした時
    println(name?.length)
    
    // nullだった場合に代わりの値を使う時
    println(name?.length ?: -1)
    
    // 5 は 1〜10 の範囲に入っているか？
    println(5 in 1..10)
}
```
